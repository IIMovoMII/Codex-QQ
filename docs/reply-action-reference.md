# QQ 助手回复与动作对照

本页汇总当前 QQ 助手的命令、卡片回复和任务通知会触发什么。动态标题、编号、模型名、请求内容和状态以目标 Desktop 对话实际返回为准；助手不会用缺失信息猜测结果。

除帮助和首次列表查询外，每次操作都要引用对应的对话回执、任务通知或功能卡片。引用用于确定目标，不会沿用上一条消息选择的对话。

## 操作结果怎么读

| 回复结果 | 实际含义 |
| --- | --- |
| 已完成、已修改、已打开 | 原生接口返回了对应的确认信息；不等于 QQ 手机端一定收到推送。 |
| 已排队 | Codex 返回了唯一且匹配目标对话的队列编号；只确认已加入原生队列，不代表任务已经开始。 |
| 未执行、未修改、未排队 | 操作未提交到目标原生入口，按回复提示修复或重新发送即可。 |
| 结果未确认、可能已执行 | 原生操作可能已经发生；先在电脑检查目标对话，不要马上重复。 |
| 目标过期、请求已变化 | 卡片属于旧连接或旧请求；助手没有把操作套用到相似对话或新请求。 |

## 查找和选择对话

| 你发送 | 助手回复 | 实际动作 |
| --- | --- | --- |
| `帮助`、`帮助 对话/任务/设置/待办` | 对应的帮助页 | 只显示用法，不读写目标对话。帮助不需要引用。 |
| `项目` | 项目列表 | 只读取本地项目目录。引用列表回复序号会生成项目卡片。 |
| `对话`、`对话 20` | 最近对话列表 | 只读取本机对话目录和可用状态；默认 10 条，数量可为 1～50。 |
| `搜索 关键词` | 标题搜索结果 | 只查找对话标题；引用项目卡片时限定在该项目。 |
| 引用列表回复序号 | 项目卡或对话卡 | 项目序号只选择项目；对话序号按精确 thread ID 打开并核对该对话，不开始任务。 |
| `下一页` | 下一页列表 | 只显示当前列表剩余项目；没有剩余项时说明列表已结束。 |
| 无引用发送控制命令，或引用过期/不属于当前身份的卡片 | 缺少目标、引用过期或无法核实目标 | 不执行命令；重新发送「对话」并选择目标。 |

## 任务和待发送队列

| 你发送 | 助手回复 | 实际动作 |
| --- | --- | --- |
| 普通正文、`发送 正文`、`继续` | 空闲或暂停时返回目标对话回执；运行中返回带队列编号的发送回执 | 空闲/暂停时开始新一轮并沿用该对话设置。运行中通过 `codex queue --thread <目标对话编号> --message <正文>` 追加到 Codex 原生可见队列；不改写整份队列，也不自动改成引导。 |
| 忙时队列命令超时，或没有唯一匹配的队列编号 | “结果未确认/可能已经排队/不会重发” | 助手不会再次提交。先检查目标对话的可见待发送列表和最近消息。 |
| 引用发送回执发 `状态` | 该条消息的状态卡 | 按队列编号读取本地原生队列和 Desktop 已接受记录；无法区分已消费、删除或移出队列时会明确说明，不会据此重发。 |
| 引用发送回执发 `删除` | 删除结果或状态未确认 | 只尝试移除该队列编号对应且仍在排队的消息；不能撤回已开始的任务。 |
| 引用发送回执发 `对话` | 普通目标对话卡 | 返回同一 thread ID 的对话入口，不发送正文。 |
| `队列` | 本地可见队列列表，或“本地记录为空” | 只读取 Desktop 可核实的本地排队记录；列表为空不证明服务端没有其他记录。 |
| 引用队列列表回复序号 | 单条排队项卡片 | 显示摘要与状态，不执行、删除或转发该消息。 |
| 引用排队项发 `状态` 或 `队列` | 当前队列列表/状态 | 重新读取可见队列。 |
| 引用排队项发 `删除` | 单条删除结果 | 删除该条仍可核实的可见队列项。 |
| 引用排队项发 `引导` | 引导结果 | 先删除这条排队项，再把同一原文交给当前运行任务；这是两个动作，可能出现已删除但未引导。 |
| `暂停` | 暂停结果 | 对当前轮次调用原生中断；不会关闭助手或 Codex，也不会删除已排队消息。 |
| `引导 内容` | 引导结果 | 将内容交给执行时正在运行的任务；没有活动任务时拒绝，不会排入普通队列。 |
| `发送 暂停` 等 | 目标任务的发送回执 | 把命令字当普通正文，不执行暂停或其他控制动作。 |

## 设置和对话管理

| 你发送 | 助手回复 | 实际动作 |
| --- | --- | --- |
| `设置` | 当前模型、思考档位、权限、审批策略和运行状态 | 只读目标对话实际状态；缺失字段会标为未返回，不会用全局默认值补齐。 |
| `模型`、`思考档位` | 选项卡 | 读取本机 Desktop 提供的可选项。引用选项卡回复序号；设置模型时可附档位，例如 `2 high`。 |
| `模型 模型名 档位`、`思考档位 档位` | 修改结果及回读值 | 将选择应用于该对话的后续轮次；不替换运行中的模型，也不自动降低档位。 |
| `权限` | 权限选项卡 | 展示该对话实际权限和可选修改。再引用选项卡回复序号，然后按确认卡完整回复 `确认 选项名` 才会修改。 |
| 权限确认卡发 `取消` | 已取消 | 不修改权限；旧确认卡不再执行。 |
| `压缩上下文` | 压缩操作卡 | 空闲时调用 Desktop 原生压缩；任务运行中拒绝，不排队、不自动暂停。压缩可能调用模型。 |
| 引用压缩卡发 `压缩状态` | 当前可观察到的压缩结果 | 只查询，不重复压缩。Desktop 没有本次调用的独立操作编号时，会说明无法严格关联。 |
| `改名 新标题` | 新标题回执 | 修改引用目标对话的标题。 |
| `分支` | 分支范围确认卡 | 只预览从最近已完成位置创建分支的范围；原对话不变，新分支不会自动发送任务。 |
| 引用分支卡发 `确认分支` / `取消` | 分支结果 / 已取消 | 确认后创建分支；取消不创建。当前不支持选择更早的分支位置。 |
| `新建对话 标题` | 项目选择卡 | 开始新建向导，此时还没有创建对话或开始任务。 |
| 引用项目卡回复序号，再填写首条任务 | 首条任务确认卡 | 选择已有项目或无项目并准备任务；尚未执行。 |
| 引用确认卡发 `确认创建` / `取消` | 新对话回执 / 已取消 | 确认后创建对话并立即执行首条任务；取消不创建、不发送。 |
| `新建项目` | 当前不支持的说明 | 不调用隐藏接口，也不改写项目文件。 |

## 待办、审批和问题

| 你发送 | 助手回复 | 实际动作 |
| --- | --- | --- |
| `待办`、`问题`、`审批` | 待办列表或当前为空的说明 | 查询目标对话的原生 requests 和可解析的异步问题。状态不完整时会注明不能判断待办为空。 |
| 引用待办列表回复序号 | 单个问题或审批卡 | 重新核对原 request ID、方法、窗口和内容摘要；请求不存在或变化时不提交。 |
| 普通问题卡回复答案或选项序号 | 提交结果 | 对支持的问题提交答案；多题按卡片提示逐行填写。秘密问题不会转发到 QQ。 |
| 命令或文件审批卡回复 `允许`、`拒绝`、`取消` | 本次审批处理结果 | 只处理卡片对应的单个原生请求，不授予永久权限。 |
| 异步问题提醒/卡片 | 问题摘要及“请在电脑回答” | QQ 只读提醒；不会把回复当正文、引导或任务提交。引用提醒发 `待办` 可重新查看。 |
| 登录验证、额外授权或不支持的请求 | 请在电脑处理 | 不尝试转换成普通任务或其他审批类型。 |

## 自动任务通知

通知会带目标对话编号和可引用标识；引用通知后发出的正文仍路由到同一 thread ID。

| 通知标题/状态 | 含义与后续动作 |
| --- | --- |
| `Codex 任务已完成` | 完成事件和可用的助手回复摘要；引用后可继续安排下一轮。 |
| `Codex 任务失败` | 错误分类和摘要；引用后可继续安排修复。 |
| `Codex 任务已中断` | 当前轮次被停止；已有队列仍由 Codex 管理。 |
| `Codex 正在等待输入`、`Codex 正在等待授权` | 需要处理当前原生待办；引用通知发 `待办` 查看 QQ 支持的类型，其他类型回电脑处理。 |
| `Codex 有问题需要你回答` | 异步问题提醒。任务可能仍在工作；回答必须回电脑完成，QQ 只提醒和查看。 |
| `Codex 任务已结束，结果未确认` | 事件不足以判定成功或失败；助手不会重跑任务。到电脑查看最终回复。 |

通知摘要可能被截短；完整内容以 Desktop 对话为准。助手不根据任务安静时间推断卡死，也不把进程退出单独当作任务完成。

## 异常回复的统一含义

- 连接离线、身份不符、引用无效、接口不支持或原生预检失败：回复会说明未执行；该条消息不会等连接恢复后补跑。
- 写操作在原生调用前被拒绝：没有进入对应写入接口。
- 写操作发出后超时、返回结构不完整或本机回执保存失败：按结果未确认处理；先检查 Desktop 实际状态，不自动换接口或重发。
- 同一 QQ 消息的重复投递由本机记录去重；重新引用并发送是新的操作，助手会按当前目标和状态重新处理。
