# 首次安装

新版是独立 Windows 桌面应用，提供中文安装器和图形配置向导。[下载 1.0.2 中文安装包](https://github.com/IIMovoMII/Codex-QQ/releases/download/app-v1.0.2/CodexQQ-Setup-1.0.2-windows-x64.exe)。已有源码安装可继续使用本文末尾的入口；现用 QQ 绑定和运行数据保留。

## 准备

- Windows 10/11 x64，使用自己的普通登录用户，无需管理员权限。
- 能正常对话的 Codex Desktop；官方账号或第三方 API 均可。
- 自己的 QQ 官方机器人。没有机器人时，向导会说明创建、测试成员和凭据的位置。
- 桌面安装包内置 Python 与配套网关；Windows 缺少 WebView2 时，安装器调用微软官方安装程序，需要网络。

首次绑定通过本人 QQ 私聊进行。AppSecret 只在本机配置窗口输入；不要发给智能体、QQ 或 GitHub。群聊在绑定完成后按[使用手册](usage.md)逐个授权，默认关闭。

## 中文桌面安装器

从[GitHub 发行页面](https://github.com/IIMovoMII/Codex-QQ/releases/tag/app-v1.0.2)下载 `CodexQQ-Setup-1.0.2-windows-x64.exe`。同页提供 `SHA256SUMS.txt`、更新签名、许可证和发布说明；可用 `Get-FileHash .\CodexQQ-Setup-1.0.2-windows-x64.exe -Algorithm SHA256` 与清单核对。Windows Authenticode 代码签名与应用更新签名不同，本版未配置前者。

运行安装器，按中文提示安装到当前用户目录。默认程序路径为 `%LOCALAPPDATA%\Programs\CodexQQ`；日常使用开始菜单中的“Codex QQ 助手”。程序目录内的运行组件需完整保留。

首次启动进入以下八步。顶部将其归为准备、机器人、连接、绑定、完成五组；底部提供当前步骤的主按钮和“稍后继续”。

| 步骤 | 你需要做什么 | 确认后发生什么 |
| --- | --- | --- |
| 准备 | 点击“检查并准备” | 检查随包运行组件；Codex 暂未开启也可先配置 QQ |
| 机器人 | 按页面说明创建机器人、找到凭据、添加本人测试 QQ；点击“我已准备好” | 进入本机凭据输入页 |
| 凭据 | 填写机器人 AppID、AppSecret，按实际平台设置选择沙箱；点击“保存并连接” | 保存本次配置进度并连接 QQ，提交后清除页面密钥字段 |
| 连接 | 等待本次 QQ 连接就绪；失败时核对凭据、测试成员和网络 | 成功后进入本人绑定；可返回修改或稍后继续 |
| 绑定 | 用本人 QQ 私聊机器人发“绑定”，把返回的 OpenID 填回窗口，核对身份并勾选本人授权 | “确认绑定”保存允许控制本机的身份；OpenID 不是普通 QQ 号 |
| 启动 | 点击“启动助手” | 启动正式监听与 QQ 连接，配置时的临时连接结束 |
| 提醒 | 核对将合并的本程序钩子，点击“安装提醒钩子”或“稍后设置提醒” | 只合并本程序处理项并启用 hooks；Codex 要求信任时由你本人核对 |
| 首次操作 | 按页面图解练习引用；按需选择登录自启，点击“进入概览” | 保存偏好并显示真实连接状态；跳过的事项保留为待办 |

已有有效安装会读取原绑定并迁移本应用路径，不要求再次输入密钥或重新绑定。遇到配置冲突时保留原文件，并提供恢复说明。

## 没有 QQ 机器人时

1. 打开 [QQ 开放平台](https://q.qq.com/)，登录控制台并创建机器人，完成平台要求的认证。
2. 在“开发设置 / 开发管理”查看机器人 `AppID`，生成或查看 `AppSecret`。
3. 在沙箱、服务范围或测试成员页面加入自己的 QQ，按平台当前规则开启私信测试。
4. 回到本机向导填写凭据，等待连接就绪后再发送“绑定”。

平台登录、实名、验证码和权限由你本人完成；页面名称与资格要求以[官方文档](https://bot.q.qq.com/wiki/)和当前控制台为准。暂时未准备好可点“稍后继续”，下次打开接续进度。

## 第一次在 QQ 发任务

1. 私聊机器人发送“帮助”和“对话”。
2. 鼠标右键机器人返回的列表，再左键“引用”；核对输入框的引用预览，发送目标对话的序号。
3. 再右键刚收到的选定回执，左键“引用”，发送“设置”，核对该对话的模型、档位和权限。
4. 再引用该回执发送无害测试任务，例如“只回复连接成功，不要调用工具，不要修改文件”。
5. 在电脑确认同一对话执行，并在 QQ **聊天正文**确认收到完成通知。

每条操作都需要对应引用，一次选择不会永久锁定目标。“QQ 机器人”页的“检查连接”不发消息；“发送测试消息…”会先展示目标及固定正文，经确认后发送一次。平台受理、本机 QQ 实收和手机推送分别核对；只有你实际在手机收到后，才选择手机实收确认。

## 进度、数据与恢复

“稍后继续”保留已提交的配置进度，并停止本次临时连接；重新打开时按已保存阶段接续。结果未确认时先核对状态或诊断，不重复提交。错误凭据可返回修改，已有有效绑定不会被首次向导覆盖。

程序与数据分别存放：

| 内容 | 默认路径 |
| --- | --- |
| 桌面应用 | `%LOCALAPPDATA%\Programs\CodexQQ` |
| 助手配置、状态与通知 | `%LOCALAPPDATA%\CodexDesktopWeixin` |
| QQ 网关状态 | `%LOCALAPPDATA%\CodexCC` |

历史目录名保留兼容，并不代表安装微信。需要排错时打开“帮助与诊断”，先预览脱敏摘要再复制或导出；不上传密钥、配置全文或原始网关日志。已有安装升级见[开发与维护](development.md#更新已有安装)。

## 启动、退出、自启与卸载

关闭主窗口后助手继续在托盘运行；需要停止时使用“退出助手”。关闭 Codex 不会退出助手，退出助手也不会关闭 Codex。

“设置 → 通用”可开启登录自启，并独立回读 Windows 启用状态。登录启动直接进入托盘；“手动启动时显示”只控制你手动打开应用的行为。“已配置”需经过下次正常 Windows 登录、服务及 QQ 就绪后，才成为已验证；手动打开应用不能替代该检查。窗口位置异常时使用同页的“重置窗口布局”。

卸载前退出助手，在 Windows“已安装的应用”中卸载。卸载器只移除指向本次安装的自启和提醒钩子，保留其他处理项、Codex 配置、QQ 绑定和运行数据。若希望彻底删除个人数据，请在确认不再需要后自行处理上述两个数据目录；不要删除 Codex 自身历史。

## 源码安装

此入口用于开发或继续维护原有源码安装，需要 Python 3.11+（含 `pythonw.exe`）。普通桌面用户使用上方 EXE 即可。需要源码方式时下载仓库后运行：

```powershell
git clone https://github.com/IIMovoMII/Codex-QQ.git
cd Codex-QQ
.\install.cmd
```

没有 Git 可使用仓库的 Code → Download ZIP，解压到长期保留的目录后双击 `install.cmd`。向导自行检查环境、准备网关、连接和绑定；中断后重跑同一入口续接，不需要预先运行 `--check` 或 `--prepare`。

源码安装日常入口为 `bin/CodexQQ助手.exe`，诊断为 `.\codex-watch.cmd doctor`。项目、Python 和 `bin/app-runtime.json` 是这套入口的一部分，搬迁时须按[更新已有安装](development.md#更新已有安装)同步路径。源码卸载先关闭自启并退出，再运行 `.\codex-watch.cmd uninstall-hooks`，确认后处理源码和本应用数据。
