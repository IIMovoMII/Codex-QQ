# 首次安装

普通安装只需运行一个入口；中断后重新运行会接续进度，不用重复绑定。想交给智能体部署，复制 [README 的一句话安装](../README.md#一句话安装)即可；智能体只需按[安装指南](agent-install.md)执行。

## 准备

- Windows 10/11 x64，使用自己的普通登录用户和正常 Windows 桌面，不需要管理员权限。
- 能正常对话的 Codex Desktop；官方账号或第三方 API 都可以。
- [Python 3.11+](https://www.python.org/downloads/windows/)，包含 `pythonw.exe`。
- 自己的 QQ 官方机器人；没有时向导会提示你到 [QQ 开放平台](https://q.qq.com/) 创建。登录、实名、私聊权限、测试成员和上线要求以平台当时页面为准。

首次绑定使用 QQ 官方机器人私聊。群聊不是首次配置入口；完成绑定后如确有需要，再按[使用手册](usage.md)逐个授权可信群成员。AppSecret 只在本机安装窗口输入，不要发给智能体、QQ 或 GitHub。

## 一个入口

下载本仓库，放在当前用户可写、长期保留的文件夹。可以用 Git：

```powershell
git clone https://github.com/IIMovoMII/Codex-QQ.git
cd Codex-QQ
.\install.cmd
```

也可以在仓库页面点 **Code → Download ZIP**，解压后双击 `install.cmd`，不必安装 Git。

向导会下载并校验本项目发布的 CC Connect 适配网关，准备启动入口，再按顺序提示：

1. 在本机输入机器人 AppID、AppSecret（输入隐藏），选择是否使用沙箱。
2. 等向导确认 QQ 连接已就绪后，用自己的 QQ 私聊机器人发送「绑定」；把返回的 **OpenID** 填回安装窗口，不是普通 QQ 号。
3. 输入 `yes`，确认仅允许这个 QQ 身份控制电脑。
4. 向导启动独立助手，询问是否合并提醒钩子；确认后只合并本程序钩子和 `[features] hooks = true`，保留其他配置。
5. 在 Codex 核对并信任钩子。提示重启时，保存任务后正常重启；向导不会替你强制关闭 Desktop。

绑定前的临时连接只能查询发送者身份，不连接 Codex。绑定后才允许本人控制。平台账号、验证码、安全确认和钩子信任不能由脚本代替。

## 进度与已有安装

关闭安装窗口、输入「取消」或按 `Ctrl+C` 后，再运行同一个 `install.cmd` 继续；已有密钥和绑定会保留。已经下载并通过校验的网关不再下载，相同钩子也不会重复写入。

绑定用的临时网关由安装窗口单独管理，关闭窗口后会随之停止，不影响其他正在使用的网关。每次重新打开向导，会重新连接 QQ，最多等 45 秒，确认本次连接的 READY 事件后才提示发送「绑定」；超时或提前退出会停止本次临时进程，并给出 `logs/setup-gateway.log` 位置。不要在提示就绪前发送绑定消息。

配置写入中断也可以接续：向导先保存带校验信息的事务进度，再发布配置；完成身份确认后的绑定收尾同样可恢复。已有旧版进度格式仍可读取。若文件被手工修改、损坏或来源不明，则保留原文件并停止，避免把别人的配置当成新安装覆盖。

若提示版本或路径冲突，先看[常见问题](troubleshooting.md)，不要删配置重装。已有用户升级见[更新说明](development.md#更新已有安装)。

默认数据在 `%LOCALAPPDATA%\CodexDesktopWeixin`，QQ 数据在 `%LOCALAPPDATA%\CodexCC`；历史目录名不代表安装微信。项目目录、Python 和生成的 `bin/app-runtime.json` 是应用的一部分，不要只复制 exe 或随意搬动目录。

安装失败时，界面会显示失败阶段、可用的退出码、错误摘要及诊断日志路径。完整诊断输出会脱敏保存在本机日志中；分享前仍请检查，不要上传配置文件或原始网关日志。

## 手机验收

用户信任钩子、Codex 有新的对话活动后，在 QQ 操作：

1. 发「帮助」「对话」，引用列表选序号，确认项目和标题。
2. 引用选定回执发「设置」，核对模型、档位和权限。
3. 引用回执发无害测试任务，在电脑确认进入同一对话。
4. 等任务完成，在 **QQ 聊天页面**确认能看见正文，而不只是通知横幅。

需要诊断时运行 `.\codex-watch.cmd doctor`。`ready` 只表示本地服务就绪，不代表手机已收到消息。完整操作见[使用手册](usage.md)。

## 开启、退出与卸载

- 开启：双击 `bin/CodexQQ助手.exe`；托盘右键可看状态、打开日志、退出。
- 独立运行：关闭 Codex 不会退出助手，退出助手也不会关闭 Codex。
- 自启：托盘菜单按需开启，默认关闭。
- 卸载：先在托盘关闭自启并退出，运行 `.\codex-watch.cmd uninstall-hooks` 移除本程序钩子。确认后再删除项目和本应用数据；数据内含密钥及消息状态，勿分享。不要删除 Codex 自身配置或历史。
