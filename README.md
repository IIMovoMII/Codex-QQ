# Codex-QQ

### 电脑负责跑任务，QQ 负责接消息、下指令。

把正在使用的 **Codex Desktop** 接到手机 QQ。<br>
任务完成、出错、需要你决定时收到提醒；引用一条消息，就能回到对应对话。

## 不用守着电脑等它跑完

你让 Codex 检查一个项目，合上手机去做别的事。过一会儿，QQ 收到：

~~~text
✅ 【个人网站】Codex 任务已完成

登录问题已修复，相关测试通过。

你引用这条消息：
再检查一下手机上的显示效果
~~~

这条回复会发回**原来的 Codex 对话**，不用在手机上输入长长的对话编号。

> 上面是虚构的交互示例。实际提醒会保留引用定位信息；较长回复会截短，完整内容仍在电脑上。

## 能做什么

| 你想做的事 | 在 QQ 里怎么做 |
| --- | --- |
| 知道任务做完、报错或需要处理了 | 接收完成、错误、暂停、问题和审批提醒 |
| 接着安排工作 | 引用提醒或对话回执，直接发送正文或「继续」 |
| 让它停一下，或者改个方向 | 引用发送「暂停」或「引导 先检查登录问题」 |
| 在多个项目、聊天之间切换 | 发「项目」「对话」「搜索 关键词」，引用列表回复序号 |
| 管理待发送消息 | 引用目标发「队列」，选中条目后可删除，或将原文转为当前任务的引导 |
| 调整模型、思考档位与权限 | 引用发「设置」「模型」「思考档位」「权限」 |
| 从手机开个新任务 | 引用发「新建对话 标题」，选项目、写任务、确认后执行 |
| 管理当前聊天 | 改名、从最近完成位置分支、空闲时压缩上下文 |
| 在可信群里操作 | 默认关闭；逐个配置群与成员后，授权成员才能在该群控制 |

普通问题、命令和文件审批已接入对应卡片；**异步问题只提醒，回答仍在电脑上完成**。群聊需要单独配置精确的群与成员组合，群内回复对其他成员可见；独立任务提醒仍发到已配置的通知会话。详细操作与边界见[使用手册](docs/usage.md)。

## 为什么用它

- **控制的就是 Desktop。** 继续电脑上已有的上下文，窗口同步显示结果；不另起一个 Codex CLI Agent。
- **引用就是选目标。** 不记编号、不猜“最近聊天”，旧回执也能继续引用。没有引用，就不会误操作别的对话。
- **旧对话也能从手机打开。** Codex 运行着，引用对话列表选序号即可尝试载入；等「已打开并连接」再发任务，不用先在电脑点开聊天。
- **官方账号、第三方 API 都能用。** 沿用目标对话自己的模型、档位和权限，不接管你的账号切换。
- **不需要自己的服务器或公网端口。** 本机应用通过 CC Connect 连接 QQ 官方机器人；手机继续用熟悉的 QQ。
- **独立托盘应用。** 手动启动，可选 Windows 登录自启。退出 Codex 后助手仍在，退出助手也不会关闭 Codex。
- **尽量轻。** Python 标准库＋Windows 原生托盘＋精简 QQ 网关，没有 Electron；监听增量事件，不把全部历史反复扫一遍。
- **监控不调用模型。** 状态判断和指令路由不额外消耗模型额度；你安排的任务、引导或压缩照常使用 Codex 额度。

消息会经过 QQ 平台。本项目由社区开发，与 OpenAI、腾讯无隶属关系。

## 开始使用

### 一句话安装

把这句话发给**能操作你本机文件和终端的 Codex、Claude 等智能体**：

~~~text
阅读 https://github.com/IIMovoMII/Codex-QQ ，按照智能体安装指南在我的电脑上部署 Codex-QQ。
~~~

智能体会按[安装指南](docs/agent-install.md)在项目目录运行一次 `install.cmd`；向导自动检查环境、准备程序并接续中断的进度。第一次使用没有机器人时，向导会逐步告诉你到 QQ 开放平台创建、查找 AppID/AppSecret 和加入自己的测试 QQ；然后只在本机输入密钥、完成 QQ 绑定并确认钩子信任。没有本机操作能力的网页聊天只能提供同样的步骤指导。

### 手动安装

当前支持 **Windows 10/11 x64**，需要可用的 Codex Desktop、Python 3.11+ 和自己的 QQ 官方机器人。安装向导自动下载并校验本仓库发布的配套网关。

~~~powershell
git clone https://github.com/IIMovoMII/Codex-QQ.git
cd Codex-QQ
.\install.cmd
~~~

没有 Git？用仓库顶部的 **Code → Download ZIP**，解压到长期保留的文件夹，双击 `install.cmd` 即可。

向导会自动准备程序、启动配置连接，再提示你完成：

1. 配置自己的机器人，并在 QQ 私聊中绑定自己的身份；群聊是绑定完成后的可选功能。
2. 确认合并本程序钩子，再到 Desktop 核对并信任。
3. 向机器人发「帮助」，检查选定对话、发送任务和结果提醒。

已有绑定会保留，不会替你改模型、登录态或历史。以后双击 `bin/CodexQQ助手.exe` 开启，托盘右键退出或按需开启登录自启。详见[首次安装](docs/install.md)与[更新说明](docs/development.md#更新已有安装)。

### 第一次发任务

~~~text
发「对话」
  → 引用返回的列表，回复「1」
  → 引用选定回执，发送「检查一下登录页面」
~~~

空闲或暂停后普通正文会开始新一轮；运行中普通正文会明确拒绝，不会偷偷写入或覆盖 Desktop 队列。想马上给当前任务补充要求，用「引导 内容」；也可以等任务空闲后再重发。每次都引用对应对话，多个项目也不串线。

### 手机里的帮助

发「帮助」看简短首页；需要时再看分类，不一次塞给你整本说明书：

~~~text
帮助 对话    查找、新建、改名、分支
帮助 任务    发送、继续、暂停、引导、排队
帮助 设置    模型、思考档位、权限、压缩
帮助 待办    问题和审批怎么处理
~~~

## 目前的边界

- 当前实现针对 **Windows 的本地 Codex 对话和 QQ 官方机器人**。首次绑定仍走私聊；群聊可在绑定完成后按“群 OpenID/成员 OpenID”逐条授权，默认不开放整群，也不是 ChatGPT 云端聊天控制器或飞书通道。
- Codex 未启动或连接失败时，新控制指令直接作废，不会在下次开机突然补执行。已经受理的任务、已有原生排队消息与结果通知分别处理。
- 可在已有项目或无项目下新建对话；暂不支持创建新项目。分支只支持最近完成位置，不能指定任意历史消息。
- 不提供历史消息编辑、归档/恢复或排队消息编辑。忙时普通正文不改写 Desktop 的整份队列；请使用「引导 内容」或等待空闲。已有队列卡片的「引导」会先删除所选的可见排队项，再把相同正文发给当前运行任务；这是两个原生操作，不是原子事务。队列展示可能不含服务端记录。
- 使用 Desktop 的本地接口，**不绑定安装版本号，也不能保证未来所有版本都兼容**。某项接口不兼容时拒绝该操作，不冒险改历史。
- 项目来自个人连续使用，通知和多项控制有实机使用记录；问题/审批等部分路径仍主要由自动测试覆盖。不是跨设备全面验收或企业级可用性承诺。

QQ 的消息额度、频率和可见性受平台规则影响；“接口接受了”不等于手机一定弹窗。电脑要保持开机联网，锁屏可用，睡眠时不能继续工作。

## 隐私与权限

你允许的 QQ 身份可以指挥本机 Codex，能力取决于目标对话的权限。请只绑定自己的身份，保护好机器人密钥和 QQ 账号。

提醒可能包含对话标题、模型名称、回复摘要、问题或错误摘要；QQ 不是端到端加密的私人执行通道。源码仓库不包含作者的密钥、绑定、聊天历史或运行数据。详见[隐私与安全说明](SECURITY.md)。

## 开发与反馈

开发与排错先看[长期维护入口](MAINTENANCE.md)，快速定位源码、测试与当前功能边界。

~~~powershell
py -3 -X utf8 -m unittest discover -s tests -v
~~~

测试不需要真实 QQ 凭据，也不会向你的 Codex 提交任务。Windows 原生交互用隔离测试验证；手机实收与不同机器的兼容性仍需人工验收。

欢迎提交复现步骤、兼容性修复和功能改进。报告问题前请先[运行诊断](docs/troubleshooting.md)，**不要上传完整配置或聊天日志**。
